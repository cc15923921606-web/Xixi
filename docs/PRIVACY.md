# 隐私与本地数据

## 数据位置

公开版将程序文件和用户数据分开保存。聊天记录、长期记忆、成长记录、设置、日志、浏览器数据、下载内容和本地组件都写入当前安装对应的用户数据目录。

覆盖升级会保留用户数据。卸载程序默认也不会擅自删除用户数据，避免误删记忆和配置。

## 凭据

模型 API 密钥通过当前 Windows 用户的凭据管理器保存。源码仓库、公开配置、构建清单和安装包都不应包含维护者或测试者的真实密钥。

## 麦克风与屏幕

- 麦克风只在语音输入、语音通话或游戏陪伴通话开启后使用。
- 屏幕画面只在用户主动开启游戏陪伴后采集。
- 关闭相关功能或退出应用后，对应采集任务应停止。
- 游戏陪伴的临时画面用于当前分析，不应作为逐帧图片永久保存。

## QQ

QQ 登录和消息处理依赖可选的 NapCatQQ 组件。用户应单独准备机器人账号，并了解 QQ 平台及 NapCatQQ 的使用条款和风险。

## 公开版隔离

公开构建会使用单独的人格模板和初始兴趣数据，并通过隐私审计阻止个人 QQ、姓名、本机路径、密钥、聊天记录、记忆数据库和浏览器缓存进入发行包。
