# 故障排查

## 麦克风曾被拒绝

打开“设置 > 基础与启动 > 设备权限”，开启麦克风权限并点击“检测麦克风”。若 Windows 仍然阻止访问，点击“Windows 设置”，同时确认系统级麦克风访问和桌面应用访问均已开启。

## QQ 二维码不显示或登录后不继续

1. 在“设置 > 环境配置”确认 NapCatQQ 已识别。
2. 在 QQ 设置中重新检测组件。
3. 刷新二维码并完成扫码确认。
4. 登录后等待状态从“正在登录”切换为“在线”。
5. 若仍失败，完全退出昔夕后重新启动，并提交已脱敏的应用日志。

## 本地语音不可用

1. 在“设置 > 环境配置”检查昔夕本地语音系统。
2. 缺少文件时使用组件修复，程序应只补下载缺失或校验失败的文件。
3. 检查磁盘剩余空间和安全软件拦截记录。
4. 确认下载完成后重新执行语音检测。

## 应用关闭后无法再次启动

正常关闭后桌面进程、后端和子服务都应退出。若仍无法启动，请在任务管理器中确认没有残留的 `Xixi.exe`，并提交日志目录中最新的脱敏日志。

## 提交问题前

- 删除截图和日志中的 API 密钥、QQ 号、群号、真实姓名及本机用户名。
- 写明应用版本、Windows 版本、操作步骤和实际提示。
- 不要上传聊天数据库、凭据文件或完整用户数据目录。
