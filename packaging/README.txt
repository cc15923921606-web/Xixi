昔夕 Windows 版

安装后，程序本体与用户数据分开保存：
- 安装目录只保存昔夕程序、界面资源和内置模型。
- 首次启动会在安装目录旁创建“<安装目录名称>数据”。
- 安装目录中的“数据目录.txt”记录当前数据位置。
- 聊天、记忆、人格修改、QQ 配置、日志、浏览器缓存、下载和本地组件都保存在独立数据目录中。
- 覆盖安装和版本升级不会删除独立数据目录；卸载后数据也会保留，便于重新安装后继续使用。

首次安装时可以自由选择安装目录，也可以选择开始菜单文件夹名称或勾选“不创建开始菜单文件夹”。检测到昔夕已经安装后，后续安装包只会覆盖升级原目录，不允许再选择另一个目录生成第二份。若要更换安装位置，请先从 Windows 设置中正常卸载现有安装，再重新选择目录安装。

如果检测到旧安装仍将数据写在安装目录内，昔夕会先复制并逐文件校验大小与 SHA-256，确认成功后再切换。已经安装的 QQ、本地语音等组件也会一起迁移，内置语音资源不会重复复制。旧目录不会被自动删除，迁移失败时仍使用旧数据。

首次启动不会直接进入主界面，而会先打开全屏配置中心。你需要依次完成电脑环境检查、语言模型连接、可选的独立视觉模型、关系资料和功能选择；语言模型检测成功前无法完成配置。全部步骤保存成功后，之后启动才会直接进入主界面。
安装包不包含制作者的 QQ 登录状态、API 密钥、模型供应商、聊天记录、记忆、成长记录、天气城市、浏览器缓存或日志。
安装目录内的 THIRD_PARTY_NOTICES.md 和 third_party_licenses 文件夹保存捆绑组件的来源与许可证；NapCatQQ 仅限非商业用途。

语言模型和视觉模型可以在“设置 > 模型与 API”中分别配置。API 密钥只写入当前 Windows 用户的凭据管理器。
QQ、语音识别、本地语音和本地视觉组件可以在“设置 > 环境配置”中按需安装。

本地语音和语音识别模型体积较大，首次安装或首次加载需要等待。安装期间可以在环境配置页查看进度并暂停、继续或取消。
